# Cardrona & Treble Cone — WeChat-style Preview

This repository contains a browser-based demonstration resembling a WeChat Mini Program. It is **not** a published native WeChat Mini Program, and orders/payments are simulated.

## Publishing on GitHub Pages

1. Upload **all the files and the `assets/` folder**, not the ZIP, to the repository root.
2. In GitHub go to Settings → Pages → Build and deployment → Source: **Deploy from a branch**, branch: **main**, folder: **/(root)** → Save.
3. Open `https://YOUR-USERNAME.github.io/cardrona-mini-preview/#/` after GitHub publishes it.

## Important limitations

- No actual WeChat login or WeChat Pay integration; no Aspenware API; no live booking inventory.
- Use fictional test details only in the demonstration checkout.
- Data is stored only in the browser.
- Before making assets public, ensure you have permission to use resort imagery and branding.
- The native WeChat development starter is available in the separate source package.
